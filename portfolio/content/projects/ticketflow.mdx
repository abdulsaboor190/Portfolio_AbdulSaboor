## Problem

Campus maintenance issues — a broken tap, a flickering light, a clogged drain — get reported in person or over group chats and then disappear. There was no single place to file a report, track who owns it, or see what happened to it.

## What I built

A full-stack ticketing system for reporting and resolving campus issues, with JWT authentication and role-based access for Reporters, Technicians, and Admins. I implemented REST APIs with an enforced ticket status workflow, assignment, comments, and a status-change audit history, backed by a relational PostgreSQL schema.

## Architecture

<ArchitectureDiagram
  src="/media/ticketflow/architecture.svg"

The React frontend talks to an Express REST API. JWT bearer tokens carry the user's role, and the API enforces which actions each role can perform. All state lives in a relational PostgreSQL schema, including the audit history of every status change.
