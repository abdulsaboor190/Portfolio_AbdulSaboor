## Problem

Fixed-time traffic signals run on a schedule regardless of actual traffic. When one approach backs up, vehicles wait even when the cross street is empty. I wanted a signal controller that could see the intersection and respond to what was actually happening.

## What I built

A system that estimates vehicle density with YOLOv8 and adjusts signal timing using a PPO agent trained in SUMO. On top of that, I built a FastAPI + React dashboard that streams live traffic metrics over WebSockets, with emergency-vehicle signal preemption.

## Architecture

The perception side runs YOLOv8 detections and reduces them to a density estimate per approach. The decision side is a PPO agent trained inside SUMO, which outputs signal timing. A FastAPI backend exposes the metrics and handles emergency-vehicle preemption, streaming updates to the React dashboard over WebSockets.
