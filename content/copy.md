## 2. PROJECT SUMMARIES

### AI-Powered Adaptive Traffic Control System

**Outcome:** A working simulation where computer vision and reinforcement
learning adjust traffic signals in real time.

**Description:** The system estimates vehicle density with YOLOv8 and uses a
PPO agent trained in SUMO to adjust signal timing. A FastAPI + React
dashboard streams live traffic metrics over WebSockets and gives emergency
vehicles signal preemption.

**Stack:** Python · YOLOv8 · PyTorch · Stable-Baselines3 (PPO) · SUMO ·
FastAPI · React · WebSockets

### TicketFlow — Campus Maintenance & Issue Tracking System

**Outcome:** A role-based ticketing system that moves campus maintenance
requests through a defined workflow.

**Description:** TicketFlow handles reporting, assignment, comments, and a
audited status-change history for campus maintenance issues. JWT
authentication and role-based access split the experience across Reporters,
Technicians, and Admins.

**Stack:** Next.js · TypeScript · Node.js/Express · PostgreSQL · JWT

### Scholr — Student Book Sharing App

**Outcome:** A campus-only mobile app for giving books a second life.

**Description:** Scholr lets students list, browse, and request books within
their campus network, with real-time messaging between users. The backend
services are containerized with Docker.

**Stack:** React Native · Node.js · Docker
