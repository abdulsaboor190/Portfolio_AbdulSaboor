## Feature rule — ShieldHer

**ShieldHer appears in the featured bento ONLY IF it has a working demo
(live URL or video) OR a public repo with a README.**

- If yes → keeps the 4th medium tile with `In progress` chip.
- If no → it drops to the editorial "More projects" list as
  "ShieldHer — in progress", and FSCM or FAST Past Papers takes the 4th
  tile if it qualifies.
- Rationale: an in-progress project earns bento space by showing work,
  not by claiming it. A tile with no proof is the exact "generic template"
  look the bento rules forbid.
